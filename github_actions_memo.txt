一个项目在上线前，安全和质量风险从哪里来？我认为有四个来源，每个来源对应一类防线。

风险来源	                    具体例子	                                对应防线
你自己写的代码有缺陷	        SQL 注入、XSS、把客户端入参当可信数据	    静态分析（CodeQL、Semgrep）
你引入的第三方代码有问题	    依赖有已知漏洞，或被投毒	                依赖审查、audit、Dependabot
机密信息被提交	            OpenRouter key、数据库连接串进了 git 历史	密钥扫描（Gitleaks）
代码根本不能正常工作	        类型错误、构建失败、格式混乱	                lint、tsc、build

还有第五类，工具解决不了：鉴权逻辑漏洞和业务逻辑错误。
