src> routers> xxx> route.tsx 定义当前路由布局： 由于切换子路由时不会被卸载和重新渲染的，路由布局不能用于做鉴权。切换子路由时 React 只是在这个布局内部替换了 <Outlet/> 里的子组件

撤销历史上提交的文件：
1. 安装git-filter-repo: uv tool install git-filter-repo
2. 本地隔离原有仓库：git clone <原仓库地址>
3. 备份要删除的文件
4. 删除文件: git filter-repo --path <path/to/file> --invert-paths
5. 确认没有要删除文件信息： git log --all --full-history -- <path/to/file>
6. 恢复备份文件
7. 检查.gitignore 是否包含删除文件: git status
8. 关联原仓库：git remote add origin <原仓库地址>
9. 强制推送到远程仓库: git push -u --force --all origin
